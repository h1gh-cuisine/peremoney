# Архитектура

## Компоненты

```text
Browser
  │ HTTP + Bearer JWT
  ▼
Next.js 15 / React 19 (client, :3010)
  │ REST /api
  ▼
NestJS 11 (server, :4010)
  ├── Prisma 6 ── PostgreSQL 17 (:5433)
  ├── Leads Factory Open API
  ├── Tochka UAPI + signed webhook
  └── Telegram Bot API (уведомления)
```

Frontend построен на Next.js App Router, Zustand и SCSS Modules. Страницы статически пререндерятся, но данные загружаются в браузере из API; отметка `○ Static` в `next build` не означает статичность бизнес-данных.

Backend — модульный NestJS API:

- `auth` — логин, текущая сессия, logout и JWT.
- `cabinets` — проекты, пользователи, настройки и создание проекта у провайдера.
- `crm` — синхронизация ответов, контакты, лиды и звонки.
- `sources` — источники, теги и фоновые domain jobs.
- `scheduler` — постановка, блокировка, повтор и аудит периодических задач.
- `finance` — плательщики, счета, платежи, баланс и аналитика.
- `tochka` — создание/PDF счёта и обработка банковского webhook.
- `fanout` — приём лида и доставка нескольким кабинетам.

## Потоки

### Синхронизация CRM

Scheduler или ручной запрос получает страницы answers из Leads Factory. Ответы нормализуются и upsert-ятся по `(cabinetId, providerAnswerId)`. Квалифицированные ответы формируют лиды. Повторный прогон идемпотентен.

### Создание проекта

MASTER отправляет параметры и idempotency key. Backend создаёт проект в Leads Factory, затем локальный кабинет и пользователей `FULL`/`LIMITED`. Статус операции хранится в `ProviderProjectCreation`, чтобы различать успех, отказ и неопределённый сетевой результат.

### Счёт и оплата

Backend проверяет плательщика и конфигурацию, создаёт локальную операцию, вызывает Точку и сохраняет `documentId`. 4xx провайдера переводит создание в `FAILED`, неоднозначная сетевая ошибка — в `UNCERTAIN`. Подписанный webhook сопоставляется по ИНН, сумме и номеру счёта; затем идемпотентно создаётся проводка баланса.

### Планировщик

Задачи сохраняются в БД. Worker захватывает их через `FOR UPDATE SKIP LOCKED`, восстанавливает зависшие операции старше 30 минут и повторяет ошибку до трёх раз с экспоненциальной задержкой.
